# 拾声 · XianDial（2.8″ 硬件版）

**一台 ESP32-S3 桌面网络收音机：13 栏目 / 42 地区的网络电台直播 ＋ TF 卡本地音频 ＋ 语音控制。**

> 烧录 / Flashing: [FLASHING.md](FLASHING.md)
>
> 当前固件版本：**v2.8.0**（2.8″ 平台首版）
>
> 名字取「拾取声音」。屏幕是 2.8 英寸 IPS 横屏（320×240），摆在案头听电台。
> 底座与开源项目 **拾声集 XianDial Suite**（3.5″ 竖屏四合一）同源：
> 同一套显示 / 触摸 / 字库 / 音频 / 电源服务层，只换界面层与板级驱动。

---

## 功能

| 做什么 | 说明 |
|---|---|
| **网络电台直播** | 按 13 栏目 / 42 地区筛选；明文 HTTP、HTTPS 直连、**HLS**（`.m3u8`）三种源 |
| **本地音频** | TF 卡里的 mp3 播放，**带续播**（下次开机从上次听到的位置继续） |
| **收藏 / 历史** | 收藏电台、最近播放，都可在界面上删 |
| **播放模式** | 连播 / 单曲 / 随机，三颗独立键；另有倍速 |
| **手势** | 播放页滑动切台、上下滑音量 |
| **语音** | 唤醒词「**Hi，喵喵**」＋ 36 条命令词（栏目点播、切台、音量、播放控制、关机） |
| **配网** | 手机连设备热点 → 打开 `192.168.4.1` → 填 WiFi 密码 |
| **其他** | 实时频谱、睡眠定时（渐弱）、音量 / 亮度按键（步进 10）、电量显示、deep sleep 关机 |

### 语音能做什么、不能做什么

**能做**（唤醒后 6 秒内说）：

| 类别 | 说法 |
|---|---|
| 栏目点播 | 播放新闻 ｜ 播放交通 ｜ 播放音乐 ｜ 播放文艺 ｜ 播放说书 ｜ 播放戏曲 ｜ 播放怀旧 ｜ 播放教育 ｜ 播放宗教 ｜ 播放境外 |
| 切台 | 下一台 ｜ 上一台 |
| 音量 | 声音大一点 ｜ 声音小一点 ｜ 静音（再说一次取消） |
| 播放控制 | 播放 ｜ 暂停 ｜ 停止 ｜ 再听一次 |
| 其他 | 收藏这台 ｜ 取消收藏 ｜ 关机 |

**不能做**：说具体台名。ESP-SR 的 MultiNet 是**命令词识别**，不是通用语音识别 ——
把上千个台名喂进去会让识别率崩掉。要听某个特定的台，说它所属的**栏目**。

**语音与播放互斥**：这块板上麦克风（ES8311 ADC）与喇叭（DAC）共用一组 I2S，
TX/RX 共享 BCLK/WS ⇒ **16 kHz 收音与 44.1 kHz 放音没法同时跑**。
所以固件是「**空闲才听**」：不播放时自动开麦，一起播就让路，停播再自动恢复。

## ★★ 先说清楚：两种形态（台单）

本仓库按**发布版**形态发布。台单（电台清单）是两种形态唯一的区别：

| | **发布版**（本仓库默认，`main/net_stations_pub.c` 存在时） | **自用版** |
|---|---|---|
| 内置台单 | **0 条** | **1254 条**（含港澳台 / 海外） |
| 台名字库 | `fonts/xs_font_pub_st16.c`（GB2312 全集 ∪ cp950 全 ＝ 16124 字 / 2 bpp） | `fonts/xs_font_st16.c`（按本机台单用字烘 776 字 / 4 bpp） |
| SD 页大字符集 | `fonts/xs_font_pub_cjk12.c`（GB2312 一二级） | `fonts/xs_font_cjk12.c`（**多并了台单那 750 字**） |
| 收藏播种 | 不播种（`XS_FAV_PUBLISH=1`） | 播种本机常听 10 台 |

**为什么发布版要把台单清干净**：台单不是内容，是一份**索引**；
随固件分发等于替别人广播，而其中有些地址是本机实测才拿到的。
⇒ 发布版台单置空，**你自己的电台由你推给自己的机器**（下一节）。

> ★★ **「台单文件不传」是不够的** —— 同一个台单会以**三种形态**进产物：
> ① `main/net_stations.c`（清单本体）；
> ② `fonts/xs_font_st16.c`（**按本机台单用字烘的字形**）；
> ③ `fonts/xs_font_cjk12.c`（并了台单那 750 字）。
> 少切任何一个，都等于把台单以**字形**形式留在固件里。
> 这三样连同 ④ 收藏播种名单，全部挂在本仓库的 `.gitignore` 与
> `main/CMakeLists.txt` 那**同一个 `if(EXISTS net_stations_pub.c)` 分支**上。
>
> ★ 判别手上这版固件是哪种形态，**只有一条路**：去 `build/es28-suite.bin` 里数台名。
> 两个台单文件同时在时，CMake 会**静默**走发布分支 —— 源码扫描查不出这件事。

### 想编自用版（要自己补台单）

⚠️ 本仓库**不含** `main/net_stations.c` 与自用版字库
（`fonts/xs_font_st16.c`、`fonts/xs_font_cjk12.c`）—— 那是作者工作区的文件，
被 `.gitignore` 挡在仓库外（见上面「两种形态」）。
⇒ **clone 下来只能编发布形态**；要编自用版得先自己补齐这两样。

补齐之后，只需把开关文件挪开（不用改任何代码）：

```bash
mv  main/net_stations_pub.c  main/net_stations_pub.c.HOLD
touch main/CMakeLists.txt    # ★ EXISTS 是【配置期】求值，不 touch 不生效
idf.py build
mv  main/net_stations_pub.c.HOLD  main/net_stations_pub.c
```

> ⚠️ **最后一行别忘**：`net_stations_pub.c` 不在 = 当前是自用形态；
> 忘了恢复，下次编出来的就是自用版。作者工作区里这件事由
> `_build_es28_self.py` 自动收尾（`try/finally`，无论成败都恢复），
> 那个脚本不进仓库。

## 加自己的电台：三步

### ① 准备一份 TSV

四列，**TAB** 分隔，UTF-8 无 BOM、LF 换行：

```
台名	栏目	地区	URL
示例电台甲	音乐	上海	http://example.com/live/64k.mp3
示例电台乙	新闻综合	全国	http://example.com/live/playlist.m3u8
```

> ★ **不想手写就用 `XianForge.html`**（Release 资产里，或仓库
> [`tools/XianForge.html`](tools/XianForge.html)）：双击用浏览器打开，
> 把 M3U / TXT / 粘贴的播放列表丢进去，它转好 `stations.tsv`。
> **完全离线运行，不上传任何数据。**

- **栏目**必须落在 13 个标准名里：
  `新闻综合 交通台 音乐 文艺 说书 戏曲 怀旧老歌 网络台 教育台 电视伴音 综合 宗教 境外新闻`
- **地区**必须落在 42 个标准名里（31 个国内省级 + 中国台湾 / 中国香港 / 中国澳门 +
  其他华语 / 北美 / 欧洲 / 日韩 / 新马 / 东南亚 / 大洋洲 / 海外中文），或填 `全国`
- **URL** 支持明文 HTTP、HTTPS 直连、以及 **HLS**（`.m3u8`）

### ② 放进 TF 卡（`/sdcard/stations.tsv`，卡根目录）

直接拔卡用读卡器拷，或走串口推。

### ③ 台名不会显示成方块

发布版那份台名字库是 **GB2312 全集 ∪ cp950 全**（两岸三地日常用字），
绝大多数台名直接可用。若你的台名里有这之外的极生僻字，就得重烘字库 ——
那需要作者侧的字体生成器与上游 TTF（霞鹜文楷 LXGW WenKai，OFL-1.1），
两者都不在本仓库内（TTF 二十多 MB，按 OFL 也不必随包分发）。

> 为什么台名要单独一套字库、为什么不干脆用全字集：见下面「字体」一节。

## 硬件规格

作者自用机的实测配置。**这份固件只在这套硬件上验证过** ——
换屏、换触摸控制器、换音频通路都需要改代码。

| 项 | 规格 |
|---|---|
| 板子 | **LCDWiki ES3C28P**（ESP32-S3） |
| 主控 | ESP32-S3（512 KB SRAM / **8 MB PSRAM** / 16 MB flash，即 N16R8） |
| 屏幕 | **2.8 英寸 IPS TFT**，**320×240**，ILI9341V，**4-line SPI**（40 MHz） |
| 触摸 | FT6336G 电容触摸（I²C，地址 `0x38`） |
| 音频 | ES8311 codec → FM8002E 功放，单声道喇叭（`PA_EN` = IO1，**低电平使能**） |
| 存储 | 板载 TF 卡座（SDIO 四线） |
| 电源 | 3.7 V 锂电池 + LDO；电池电压 ADC 取样在 **IO9**；支持 deep sleep 关机 |
| 框架 | ESP-IDF 6.1 + LVGL 9 |
| 分区 | app 7 MB ＋ **模型分区 6 MB**，**无 OTA**，升级需重新烧录 |

**⚠️ 这块板的电池 ADC 在 IO9，不是 IO8。** 同一个 IO8 在 3.5″ 板（拾声集）上是电池脚，
在这块板上是 **I2S 数据输出（DOUT）**。早期固件照抄了 3.5 的 `ADC_CHANNEL_7`(=IO8)，
结果电池检测把音频输出脚配成模拟输入，**整机没声音**。
现在 `app_pins.h` 给了 2.8 自己的 `BAT_ADC_UNIT/CHAN`，`app_pwr_init()` 还会在启动时
用 `adc_oneshot_io_to_channel()` 做一次**运行时自检**，配错会直接打 `★★★ ADC 配错！`。

> ★ **不要跨板照抄引脚** —— IO38/39、41、42、47/48 在两块板上的含义完全不同。
>
> ★ **朝向**：屏的 `LCD_MIRROR_X` 与触摸的 `TP_MIRROR_X` 在本板上是**不同的值**
> （各自由排线和贴合方式决定）。装修朝向不对时**增量必须同步**地调，
> 别只翻一边 —— 那会出现「点屏幕全落到对面」。

## 字库

界面用 **霞鹜文楷 LXGW WenKai**（SIL OFL 1.1，允许嵌入固件、允许子集化）。

| 档 | 用在哪 | 字符集 |
|---|---|---|
| 14 px | 正文、列表行、状态行 | **2118 个源码字**（扫 UI 源码） |
| 18 px | 卡片标题、按钮 | 同上 |
| 22 px | 大标题 | 同上 |
| 14 px（`xs_font_cjk12`） | **SD 页文件名**、任何用户文本 | GB2312 一二级（＋回退链终点） |
| 16 px（`xs_font_st16`） | **台名 / 栏目 / 省份** | 发布版 GB2312∪cp950；自用版按本机台单用字 |

**主字库带字体回退链**：`xs_font_14/18/22` 的 `.fallback` 都指向 `xs_font_cjk12`，
所以主字库可以保持"小而准"（字号 / 行高 / 字宽与上版逐值相同 = 零布局扰动），
缺字时 LVGL 自动顺着回退取字形，而不是显示方块。

> ★ 为什么不把汉字直接并进主字库：实测会把 14 px 那档的 `line_height` 从 **15 顶到 16~17**，
> 而界面是 240 px 高逐像素排的 ⇒ 行高多 2 px 会动整个布局。
>
> ★ **"主字库没这个字" ≠ "屏上是方块"** —— 先看回退链。

授权与保留字体名的说明见 [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md)。

## 编译与烧录

详见 **[FLASHING.md](FLASHING.md)**。要点：

| 文件 | 烧到 |
|---|---|
| `bootloader.bin` | `0x0` |
| `partition-table.bin` | `0x8000` |
| `es28-suite.bin`（应用程序） | `0x10000` |
| `model.bin`（语音模型，SPIFFS） | `0x710000` |

> ⚠️ **不要把 `es28-suite.bin` 单独刷到 `0x0`** —— 那是把应用程序写进引导程序区，板子起不来。
> ⚠️ `model.bin` 只有 **6 MB**，且**烧它不会擦掉你的配网与设置**（NVS 在 `0x9000`，地址不动）。
> 不烧 `model.bin` 也能开机，只是**语音不可用**（模型缺失是软失败，界面照常）。

## 隐私（这一节是承诺，不是宣传语）

### 这台设备在网络上做什么

**唯一会连出去的地址，是你自己填的电台地址**（发布版内置台单为 0 条）。
此外只有两处固定出站：配网页面（本机热点 `192.168.4.1`，不出网）与 SNTP 校时。

### 设备本地存了什么

- **NVS**（`xs_cfg` 命名空间）：音量、背光、静音、播放模式，以及配网用的 WiFi 凭据
- **TF 卡**：你推的台单与音频
- 没有账号、没有遥测、不上传任何使用数据

### 仓库里没有什么

- **台单**（`main/net_stations.c` 与自用版字库 `fonts/xs_font_st*.c`、`fonts/xs_font_cjk12.c`）
  —— 见上面「两种形态」
- **语音模型**（`_voice_models/`、`_voice_spiffs/`，约 5.8 MB）
  —— 是 Espressif 的模型数据，随**固件镜像**分发，不随源码仓库
- 任何凭据、token、个人路径、设备 ID

## 已知限制

- **无 OTA**：升级要重新烧录（分区表里没留 OTA 槽）
- **依赖 TLS 的台播不出来**：内部 RAM 最大连续块约 31 KB，而 TLS 握手要 16~40 KB
  **连续**内存 —— 这是硬件内存的硬限制，不是 bug
- **语音说不了台名**（见上）；且**播放时不能语音**（麦克风与喇叭的采样率冲突）
- 网络电台的音质与可用性取决于**你填的源**，本项目不保证任何地址长期可用
